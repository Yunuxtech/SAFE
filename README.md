# PTCN-LoRa Project Data

This repository contains the source data and supporting documents for the **PTCN-LoRa** project.

**PTCN-LoRa** is a personnel positioning system designed for tunnel construction environments. The project uses LoRa/RTToF ranging data, channel-state features, and a Positioning Transformer-CNN Network (PTCN) to improve worker localization accuracy in long and narrow tunnel scenarios.

## Repository Contents

This repository includes:

* Research paper PDF files
* Experimental data files
* Excel spreadsheets used for analysis
* Source records related to LoRa ranging, model evaluation, and system testing

## Project Overview

The PTCN-LoRa system combines:

* SX1280-based LoRa/RTToF ranging
* Channel-state feature collection
* PTCN neural ranging correction
* Weighted multi-base-station fusion
* Tunnel personnel positioning and safety monitoring

The main goal is to improve the reliability of low-cost LoRa-based positioning in tunnel construction environments.

## Data Description

The Excel files contain experimental records and evaluation results used in the paper, including data related to:

* Raw LoRa ranging
* Corrected ranging results
* Model performance evaluation
* Multi-base-station fusion
* Latency and system-level testing

## Usage

The files in this repository are provided for academic reference, result verification, and further research related to LoRa-based personnel positioning.

Researchers may use the data to understand the experimental setup, reproduce selected analyses, or compare future positioning methods with the reported results.
